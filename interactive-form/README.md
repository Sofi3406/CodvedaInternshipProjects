# Interactive Form Validation 📝

An interactive and user-friendly form built using **HTML, CSS, and JavaScript** 
## 📌 Project Overview

This project demonstrates **client-side form validation** using vanilla JavaScript. The form validates user input in real time, displays helpful error messages without reloading the page, and confirms successful submission with a clear message.

The focus is on **user experience 
**, **clean UI**, and **proper input validation**.

## ✨ Features

-  Real-time form validation
-  Required field checks
-  Email format validation
-  Phone number validation
-  Password strength validation
-  Dynamic error messages 
-  Focus and blur event handling
-  Success message on valid submission
-  Clean and professional UI design

## 🛠️ Technologies Used

- **HTML5** – Semantic and accessible form structure  
- **CSS3** – Clean styling, layout, and focus effects  
- **JavaScript (Vanilla)** – Input validation and DOM manipulation
